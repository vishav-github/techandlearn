Configure API Subscription Pricing — Company #68 ApiSubscription

Named tiers from config/api_tiers.php · company override in ProductCostPerClient · live subscription sync on save.

Rules preserved (must not be simplified away)
  • Lookup: company PricePerUnit → global CompanyLink=0 → $API_TIERS monthlyPrice.
  • PlanData JSON stores callLimit, volumeBytes, rpmLimit, monthlyPrice (Enterprise custom).
  • Price order: Starter ≤ Growth ≤ Professional ≤ Enterprise (when Enterprise price set).
  • Enterprise: if any of Calls / GB / RPM / Price filled, all four required and each must be > Professional effective values; RPM floor max(1000, value) on save.
  • Blank New Price on S/G/P → save uses config default. Reset one tier / Reset All deletes overrides then syncs active sub.
  • Save runs in one DB transaction with apiSubscriptionSyncActivePlanPricing; sync failure → ROLLBACK.
  • Activation Fee remains on the list row (FeatureActivationFee) — not in this modal.
  • Reference tables (definitions / RPM / top-up psychology) are read-only aids — keep them.
