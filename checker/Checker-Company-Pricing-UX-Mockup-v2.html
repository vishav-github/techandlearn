Mockup v2 · model-aware · no saves
Company: preproduction · ID 68 · Currency USD
This mockup preserves all four pricing models on this page. Bracket services stay Min–Max. The three special monthly products open dedicated editors (same fields & rules as m_company-pricing.php). Click the coloured buttons to open each modal.
Functional split (do not merge these into one editor) Standard credits/modules/storage use quantity brackets + TableEditor + overlapping-range validation. AI Chatbot / API Subscription / API Top-Up use named tiers from config, company overrides in ProductCostPerClient, and dedicated Save/Clear/Reset + (API) live subscription sync. Activation Fee remains a separate FeatureActivationFee row for AI Chatbot and API Subscription — not for API Top-Up.

① Bracket / quantity

MinAmount–MaxAmount · PricePerUnit · Add/Edit via TableEditor · MoreValidation overlap + volume-discount direction.

② AI Chatbot Connector

Named tiers Starter/Pro/Enterprise/Unlimited · calls + monthly price · AJAX Save/Clear · Activation Fee separate.

③ API Access Subscription

STARTER→ENTERPRISE · PlanData (calls/GB/RPM) · tier price order · Enterprise > Pro · sync live sub · Reset.

④ API Top-Up Package

TOPUP_STARTER/GROWTH/PROFESSIONAL · package size fixed · price override · no Activation Fee · Reset.

AI Chatbot Connector — Tier Pricing LlmChatbot

Set monthly prices for Starter, Professional, Enterprise, Unlimited. Leave blank → system defaults from $LlmTiers.

Rules preserved
  • Storage: ProductCostPerClient Type=LlmChatbot, TierCode=tier name, MinAmount=MaxAmount=calls (tier identity).
  • Save validates numeric ≥ 0 before any write; empty field → catalogue default price.
  • Clear deletes company rows (falls back to $LlmTiers).
  • CSRF token required (AJAX). Activation Fee is edited separately on the row (FeatureActivationFee).
  • Unlimited: calls = −1 (not a quantity bracket).

Configure API Subscription Pricing — Company #68 ApiSubscription

Named tiers from config/api_tiers.php · company override in ProductCostPerClient · live subscription sync on save.

Rules preserved (must not be simplified away)
  • Lookup: company PricePerUnit → global CompanyLink=0 → $API_TIERS monthlyPrice.
  • PlanData JSON stores callLimit, volumeBytes, rpmLimit, monthlyPrice (Enterprise custom).
  • Price order: Starter ≤ Growth ≤ Professional ≤ Enterprise (when Enterprise price set).
  • Enterprise: if any of Calls / GB / RPM / Price filled, all four required and each must be > Professional effective values; RPM floor max(1000, value) on save.
  • Blank New Price on S/G/P → save uses config default. Reset one tier / Reset All deletes overrides then syncs active sub.
  • Save runs in one DB transaction with apiSubscriptionSyncActivePlanPricing; sync failure → ROLLBACK.
  • Activation Fee remains on the list row (FeatureActivationFee) — not in this modal.
  • Reference tables (definitions / RPM / top-up psychology) are read-only aids — keep them.
