Live Support Console

Mockup · not production

Checker Team staff watch AI Support Agent conversations as they happen, take over the ones going badly, and answer in the same thread the user is already reading. Use the state switcher to see every state the screen has to handle.

Not to be built

These exist only to demonstrate the screen. Everything else on this page is real and specified in the roadmap.

  • The state switcher above the console — the real screen derives its state from the session row.
  • All seeded data — company names, usernames, transcripts and timers are invented.
  • Waiting timers do not tick; in the build they count up from the flag time.
  • Nothing here calls a server. The transcript does not poll, and no button sends anything.

Where this mockup and the roadmap disagree, the roadmap is authoritative and this page is stale.

What each control does

  • Take this conversation — writes an exclusive claim on the session row. Succeeds only if unclaimed; the loser of a race sees the holder's name instead.
  • Send reply — writes a human turn into the conversation through the existing compare-and-swap writer, translating into the user's language first. Disabled while the editor is empty.
  • Hand back to AI — confirmation, then the AI resumes and the user is told.
  • Close conversation — confirmation, then the session ends, records resolved by human, and offers knowledge base capture.
  • Pause refresh — stops polling without leaving the page. Client-side only.

States shown here

  • Flagged, unclaimed — amber rail, reason in words, claim control only.
  • Claimed by me — editor carries the AI draft; send, hand back and close appear.
  • Claimed by someone else — holder named, no controls at all.
  • Feed stale — last good data kept, banner names the time of the last successful refresh.
  • Nothing live — empty state in both panes, never a blank panel.
  • Draft unavailable — editor empties and the label reads so; it never blocks typing.

Keyboard and narrow widths

  • Tab order runs list → transcript → editor → actions. Every control has a visible focus ring.
  • A human joining is announced to assistive technology as a status change, not as a new message.
  • Below 760px the two panes stack; the console is a desk tool and is not required to work on a phone.
  • Long company names, long flag reasons and long single messages wrap rather than clip.
  • Both light and dark themes are specified; the console follows the viewer's setting.
