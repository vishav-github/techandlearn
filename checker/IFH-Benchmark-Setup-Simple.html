Benchmark groups

Each group is a set of clients that compare against each other, anonymously. A client belongs to one group.

Always available to managers Runs on prepaid credits — you only pay when it calculates

Select the clients that compare against each other and click Update — the characteristics they share load below (same pattern as the operations panel).

1Group & clients

Name the group, pick the clients (everyone in the group is an equal, anonymous peer), then click Update.

Clients already in another group are shown but locked (one group per client). Change the selection and click Update to reload the shared characteristics.

2Characteristic breakdowns OPTIONAL

Final, section and sub-section scores are always compared — that's the baseline. Adding characteristics is optional: it adds like-for-like breakdowns (5-star vs 5-star). Leave it empty and the group still benchmarks scores.

Score levels: Final · Section · Sub-section (all included) Score basis: normalised 0–100 index
Only characteristics common to the selected clients appear (from ClientProps). Values load on expand and pool only where labels match. Add a client that lacks a characteristic and it drops from the list.

3Period, frequency & billing

Two separate controls: which reviews the comparison is built from, and how often that period is recomputed. Each run consumes credits — one per distinct review it reads.

Privacy: comparisons with too few peers are hidden automatically Billing: prepaid credits, drawn from the company balance

4Statistics & readout

What the benchmark shows beyond your own score, in the report and dashboard.

5Preview — how the analyst sees it

The client's analyst ticks one “Benchmark” box in a report, then compares value-vs-value.
